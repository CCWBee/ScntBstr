# Sanctions Bustr

Checking a name against sanctions lists usually means a paid service or pasting the name into someone else's site. This does it in the browser, client-side: the screening runs in the page, so the names you check never leave the machine.

## Use

Open `sanctionsbustr.html`. `index.html` is a thin wrapper for embedding the same tool elsewhere, and `Sanctions Tool Updater.html` handles refreshing the underlying list data.

## Standing

A personal prototype, built in my own time. It is not a work product, and it is not affiliated with or endorsed by any employer. It is a convenience tool, not a compliance system of record; verify anything that matters against an authoritative source.
