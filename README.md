# Sanctions Bustr

Checking a name against sanctions lists usually means a paid service or pasting the name into someone else's site. This does it in the browser, entirely client-side: it works against the UK (OFSI), UN and Jersey consolidated lists, and the screening runs in the page, so the names you check never leave the machine.

## Use

Open `sanctionsbustr.html`, the tool itself. `index.html` embeds it in an iframe wrapper, and `Sanctions Tool Updater.html` is a separate utility for regenerating the bundled list data.

## Standing

A personal prototype, built in my own time. Not a work product, and not affiliated with or endorsed by any employer. It is a convenience tool, not a compliance system of record; verify anything that matters against an authoritative source.
